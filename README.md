AEDIS GLOBAL — INTEGRATED LOCAL DEMONSTRATION v0.2.2
====================================================

**The proposal this software implements:** [`proposal/AEDIS-PROPOSAL.md`](proposal/AEDIS-PROPOSAL.md) — version 3.2, reviewed by four models across eight rounds,
with their objections recorded in Appendices G, H and I of the document.


WHAT THIS BUILD IS
------------------
This release merges the visual public AEDIS demonstration with the secure-core
registration, review, directory, and ledger services. The public website and
private workspaces now operate as one connected Next.js application.

QUICK START ON WINDOWS
----------------------
1. Install and open Docker Desktop.
2. Double-click "install AEDIS.bat" once.
3. When installation finishes, AEDIS opens at http://localhost:3000
4. Later, use "start_AEDIS.bat" and "stop_AEDIS.bat".
5. Double-click "show_AEDIS_accounts.bat" to view local test credentials.

PUBLIC AREAS
------------
- AEDIS Global home
- Public transparency portal with project evidence
- Flagged cases
- Global country rollups
- Infrastructure opportunities
- Reserve allocation simulation
- Workforce transition programs
- Phase Zero resource capacity
- Approved organization directory
- Balanced public demonstration ledger

PRIVATE WORKSPACES
------------------
- Registrant: create, edit, upload to, and submit organization applications
- Reviewer: independently recommend approval, changes, or rejection
- Administrator: make final decisions after a separate reviewer recommendation

LOCAL TEST ACCOUNTS
-------------------
The installer writes generated passwords to LOCAL_TEST_ACCOUNTS.txt.
Do not reuse those passwords anywhere else.

IMPORTANT SCOPE LIMITS
----------------------
This is a local evaluation build. It is not certified for public deployment,
regulated records, banking operations, real medical information, or sovereign
security. Do not enter real identity documents or other sensitive data.

The advanced 12-region Distributed Key Generation / threshold-signature design
is NOT included. That system should be designed and independently reviewed as a
separate constitutional signing service after governance rules are finalized.
